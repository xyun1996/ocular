# Contributing to ocular

Thanks for your interest in improving ocular.

## Development

```bash
npm install
npm run build
npm test
```

## Pull requests

- Keep changes focused and explain the motivation.
- Add or update tests for behavior changes.
- Ensure `npm run check` passes before submitting.

## Issues

Please include:

- ocular version or commit
- Node.js version
- MCP client used
- model provider configuration (without secrets)
- logs or minimal reproduction steps
