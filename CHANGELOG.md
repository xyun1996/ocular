# Changelog

All notable changes to `ocular` will be documented here.

The project is currently pre-1.0, so interfaces and configuration may still evolve as real-world MCP integrations are tested.

## Unreleased

### Added

- Open-source contribution and security documentation
- Continuous integration for build and test checks
- Integration and screenshot-debugging examples
- Architecture and deployment documentation
- GitHub issue and pull request templates

### Changed

- README reorganized around project value, quick start, common workflows, and contribution paths
- npm package metadata expanded for repository discovery and future distribution

## Release process

When a release is prepared:

1. Run `npm run check`.
2. Update this changelog with the release version and date.
3. Create a GitHub release/tag.
4. Publish the npm package only after verifying the package contents and registry name.
