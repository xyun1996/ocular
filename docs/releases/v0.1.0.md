# ocular v0.1.0

`ocular` is an MCP server that gives text-first coding agents structured visual context from screenshots, UI mockups, terminal errors, documents, tables, charts, and general images.

## Highlights

- Eight focused MCP tools for image analysis, OCR, UI inspection, error diagnosis, UI comparison, table extraction, chart analysis, and remote upload orchestration
- OpenAI-compatible multimodal provider interface
- Local stdio and remote HTTP transports
- Binary upload side channel for remote deployments, using persistent content-addressed `file_id` references instead of large inline base64 payloads
- Structured JSON output designed for coding-agent reasoning
- Result caching and persistent upload storage
- CI coverage on Node.js 20 and 22
- npm package-content and installed-CLI smoke checks
- Reproducible provider compatibility and visual benchmark tooling
- Official MCP Registry metadata for `io.github.xyun1996/ocular`

## Install

The public npm package is `ocular-mcp`; it installs the executable `ocular`.

```bash
npm install -g ocular-mcp
ocular
```

Or run without a global install:

```bash
npx -y ocular-mcp
```

Minimum provider configuration:

```env
OCULAR_BASE_URL=https://your-openai-compatible-endpoint.example/v1
OCULAR_API_KEY=your_api_key
OCULAR_MODEL=your_vision_model
```

## MCP client example

A generic MCP client can launch the published package directly:

```json
{
  "mcpServers": {
    "ocular": {
      "command": "npx",
      "args": ["-y", "ocular-mcp"],
      "env": {
        "OCULAR_BASE_URL": "https://your-openai-compatible-endpoint.example/v1",
        "OCULAR_MODEL": "your_vision_model",
        "OCULAR_API_KEY": "your_api_key"
      }
    }
  }
}
```

## Example use cases

- Give a coding agent a browser or terminal screenshot and extract exact error evidence before repository-level debugging
- Analyze an implementation screenshot for hierarchy, spacing, typography, contrast, and likely frontend defects
- Compare a reference UI screenshot against an implementation screenshot
- Extract visible text, tables, and chart information into structured data

## Distribution and verification

`ocular-mcp@0.1.0` is published to the public npm Registry. A clean-install verification run installed the public package independently on Node.js 20 and 22, verified that the package exposes `bin.ocular = dist/index.js`, and executed the installed CLI through ocular's own configuration-validation path.

The repository is configured for npm Trusted Publishing through GitHub Actions OIDC for subsequent releases, avoiding a long-lived npm write token in repository secrets.

The release also includes `server.json` and npm `mcpName` metadata for publication to the official MCP Registry as:

```text
io.github.xyun1996/ocular
```

## Reproducible testing

Provider compatibility is tracked through `scripts/provider-smoke.mjs` and `docs/provider-compatibility.md`. A provider/model combination is considered verified only after a real smoke run; API compatibility is not inferred from branding alone.

The repository also includes five synthetic, redistributable visual fixtures and `scripts/benchmark-fixtures.mjs` for repeatable workflow-level measurements across error diagnosis, UI analysis/comparison, table extraction, and chart analysis.

## Known limitations

- The project is pre-1.0 and interfaces may evolve as more MCP clients and providers are tested.
- The compatibility matrix intentionally starts without unverified provider/model rows; successful real endpoint runs still need to be contributed and recorded.
- The benchmark framework is included, but public live provider/model result sets are not yet published.
- Model output quality and latency depend on the configured endpoint/model and are not guaranteed by the OpenAI-compatible request shape alone.
